# `proteus.outgas.node_record_io`

Writes the per-node record of the layer scheme into the interior snapshots and reads it back on a resume.

For how this part works, see [Outgassing, rock vapour and volatile trapping](../../Explanations/outgas.md#layer-drainage-node-by-node).
