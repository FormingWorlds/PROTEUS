# `proteus.outgas.burial_ledger`

Where trapping buried each volatile, in melt-fraction coordinates, so that a remelt returns the most recent burial first.

For how this part works, see [Outgassing, rock vapour and volatile trapping](../../Explanations/outgas.md#remelting-and-the-burial-ledger).
