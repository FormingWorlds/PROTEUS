# `proteus.outgas.node_record`

The per-node record of the layer scheme: the pore melt and phase state of every node, and the volatiles buried and locked at it.

For how this part works, see [Outgassing, rock vapour and volatile trapping](../../Explanations/outgas.md#layer-drainage-node-by-node).
