# `proteus.outgas.binodal`

The bulk H2 split between atmosphere and melt from the H2-MgSiO3 binodal. The config loader rejects `outgas.h2_binodal = true`.

For how this part works, see [Outgassing, rock vapour and volatile trapping](../../Explanations/outgas.md#hydrogen-and-silicate-melt-the-binodal).
